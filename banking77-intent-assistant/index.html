Pipeline

Four reproducible stages, each driven by a single config file. The official test split is never touched until evaluation.

1PrepareBanking77 loaded, leak-free 90/10 train/val split, chat-template rendering.
2BaselineTF-IDF + logistic regression calibrates expectations on CPU in minutes.
3Fine-tuneLoRA adapters (r=16) on all attention projections, SFTTrainer, bf16.
4Evaluate & serveStrict JSON validation, error analysis, confusion matrix, vLLM endpoint.

Strict output schema

Every model response is parsed, schema-validated with Pydantic (extra="forbid"), and checked against the 77-label vocabulary. Failures become machine-readable error records.

Quickstart

Three commands to a baseline; a GPU for the full fine-tune; a CPU smoke config to verify the whole pipeline in minutes.

# data + baseline (CPU)
python scripts/prepare_data.py --config configs/banking77.yaml
python scripts/run_baseline.py --config configs/banking77.yaml

# fine-tune + evaluate (GPU)
python scripts/train.py --config configs/banking77.yaml
python scripts/evaluate.py --config configs/banking77.yaml

# merge, serve, query
python scripts/merge_adapter.py --adapter checkpoints/<run> --out checkpoints/merged \
    --base-model Qwen/Qwen2.5-1.5B-Instruct
./scripts/serve.sh checkpoints/merged 8000
python scripts/client.py "I have been charged twice this month"

What's inside

Small, focused modules under src/llm_structured_output/, each independently tested.

data/Leak-free splits, chat-template prompts, Pydantic schema with extra="forbid".
training/PEFT LoRA on q/k/v/o projections, SFTTrainer, eval-metric history, resumable checkpoints.
evaluation/JSON extraction, schema validation, error taxonomy, confusion matrix JSON + PNG.
baseline/TF-IDF (word 1–2 grams) + balanced logistic regression — the number to beat.
inference/Client with schema enforcement, input truncation, bounded exponential-backoff retries.
configs/One YAML per experiment: full GPU run and a tiny CPU smoke run, fully reproducible.
